API Endpoints for Morgan Backend

Base URL: /api/v1 (or as configured in .env API_PATH)

Authentication
--------------
POST /api/v1/login
  Body: { "email": "<ADMIN_EMAIL>", "password": "<ADMIN_PASSWORD>" } (values come from env)
  Response: { "message": "Login successful", "token": "...", "user": { ... } }

GET /api/v1/me
  Description: Returns the logged-in admin. 401 if the token is missing or expired.

All create/update/delete endpoints and the job-applications read endpoints require:
  Authorization: Bearer <token>
Requires env: ADMIN_EMAIL, ADMIN_PASSWORD, JWT_SECRET

Jobs
----
GET /api/v1/jobs
  Description: Get all jobs (ordered by newest).
  Response: Array of Job objects.

GET /api/v1/jobs/:id
  Description: Get a single job by ID.
  Response: Job object.

POST /api/v1/jobs

PUT /api/v1/jobs/:id
  Description: Update an existing job.
  Body: fields to update...

DELETE /api/v1/jobs/:id
  Description: Delete a job.

Blog Posts
----------
GET /api/v1/fetch-blog-posts
  Description: Get all blog posts.
  Response: Array of Blog objects.

GET /api/v1/fetch-blog-post/:id
  Description: Get a single blog post by ID.

GET /api/v1/fetch-blog-post-by-slug/:slug
  Description: Get a single blog post by slug.

POST /api/v1/insertblogpost
  Description: Create a new blog post.
  Content-Type: multipart/form-data
  Body: 
    - title, slug, canonical_tag, meta_title, meta_description, meta_keywords, content (text fields)
    - blogimage (file)

PUT /api/v1/update-blog-post/:id
  Description: Update a blog post.
  Content-Type: multipart/form-data (if updating image) or application/json

DELETE /api/v1/delete-blog-post/:id
  Description: Delete a blog post.
